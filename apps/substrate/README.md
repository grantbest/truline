# substrate

The bead store. One FastAPI service over Postgres that holds every unit of work on the platform
as a **bead**: a typed, namespaced, lineaged record with provenance, state, parents, confidence
and a trust tier, plus an append-only event log of every transition.

## What it enforces

- **Typed content.** Every `(namespace, type)` pair can register a pydantic schema
  (`src/schemas.py`); a write whose content does not match is refused with the field-level
  errors. Unregistered pairs pass through, so a new vertical adds types without a core change.
- **Governed state machines.** `src/bead_rules.py` holds the legal transitions per type and the
  closed edge vocabulary between beads. A transition the machine does not declare is refused.
- **Encryption at the application layer.** Bead content and context are encrypted with
  `SUBSTRATE_ENCRYPTION_KEY` (Fernet) before they reach Postgres. The service refuses to start
  without a valid key.
- **One key, one door.** Writes need `X-API-Key: $SUBSTRATE_API_KEY`. An optional
  `SUBSTRATE_READ_API_KEY` grants read-only access.

## Run it

```bash
export DATABASE_URL=postgresql+asyncpg://alpha:alpha@127.0.0.1:5432/substrate
export SUBSTRATE_API_KEY=local-dev-key
export SUBSTRATE_ENCRYPTION_KEY=$(python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())")
export REDIS_URL=redis://127.0.0.1:6379/0      # or DISABLE_SUBSTRATE_CACHE=1
export DISABLE_VECTOR_LISTENER=1               # unless you run Qdrant and an embedding endpoint
pip install -r requirements.txt
alembic upgrade head
uvicorn src.main:app --port 8000
```

Then:

```bash
curl localhost:8000/health
curl -X POST localhost:8000/beads -H "X-API-Key: $SUBSTRATE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"namespace":"dev","type":"note","state":"pending","trust_tier":"derived","created_by":"me",
       "content":{"kind":"comment","body":"first bead"}}'
curl "localhost:8000/beads?namespace=dev" -H "X-API-Key: $SUBSTRATE_API_KEY"
```

The whole API is in `openapi.json`, regenerated by CI from the routes.

## Environment

| Var | Required | Notes |
|---|---|---|
| `DATABASE_URL` | yes | `postgresql+asyncpg://…`; migrations read the same variable |
| `SUBSTRATE_API_KEY` | yes | the write key |
| `SUBSTRATE_ENCRYPTION_KEY` | yes | Fernet key; rotating it is a runbook, not an env change |
| `SUBSTRATE_READ_API_KEY` | no | additive read-only key |
| `REDIS_URL` | no | read cache; `DISABLE_SUBSTRATE_CACHE=1` runs without one |
| `QDRANT_URL`, `QDRANT_COLLECTION` | no | semantic search; `DISABLE_VECTOR_LISTENER=1` runs without them |
| `SUBSTRATE_CORS_ORIGINS` | no | comma-separated browser origins; never a wildcard |

## Layout

| Path | What it is |
|---|---|
| `src/` | the service: `routes.py`, `schemas.py`, `bead_rules.py`, `crypto.py`, `models.py` |
| `migrations/` | Alembic; `alembic upgrade head` on every start of the image |
| `client/` | the one Python client every other app uses |
| `publish/csdm-on-beads/` | the CSDM core as a standalone, dependency-free package |
| `tests/` | the suite; `pytest tests` with a Postgres at `DATABASE_URL` |
